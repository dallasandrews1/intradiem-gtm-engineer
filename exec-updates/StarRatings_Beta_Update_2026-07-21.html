Under the hood

How the engine works, and where it scales

The point of the beta is not one campaign. It is a repeatable machine that a rep can run.

How each email is built

  • Sources the buying committee and scores account fit.
  • Drafts each email off the plan's own CMS Stars math, with no unverified claims.
  • Routes every batch to Nathan for review before anything sends. People judge, the engine drafts.

Scale path

  • The same build covers the full 32 sub-4.0 Star Ratings parents.
  • Each new wave is hours of work, not weeks, because the shared enrichment layer is already built.
  • The model extends to the next motions on the same rails.
Net: the engine is built and in-market, deliverability is clean, and the first genuine reply put us in front of the right buyer. The next few weeks are about warming into higher volume and turning these first threads into meetings.
