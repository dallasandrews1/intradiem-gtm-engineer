# GTM Engine Showcase — Deploy

A single self-contained page. `index.html` is the entrypoint. The only external
dependency is Google Fonts (loaded over CDN), so it works live with no build step.

## Get a real shareable link (pick one)

**Netlify Drop** — drag this folder onto https://app.netlify.com/drop → instant URL.

**Vercel** — `npm i -g vercel` then run `vercel` inside this folder.

**GitHub Pages** — push this folder to a repo, enable Pages on the branch root.

**Cloudflare Pages / Surge / any static host** — point it at this folder; serve `index.html`.

No server, database, or environment variables required.
