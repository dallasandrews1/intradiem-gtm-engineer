Rebuilding it

Scenes are pages, so a wording change is a text edit

motions/all_hands_sep14/scenes/
  system.html act1.html act2.html act3.html coda1.html coda2.html
  build_scenes.py        renders each ?k= keyframe and dissolves them into a scene
motions/all_hands_sep14/final_cut/
  build_final_cut.py     sources, trims, speeds and geometry, one table at the top
  add_narration.py       voice file on, cleaned and level-matched
  cues.json              the twenty-three lines and their timecodes

Each scene page draws its own state from a keyframe index in the URL, so the build-on animation is deterministic. Change a line of copy, run build_scenes.py, run build_final_cut.py, and the cut comes back with it.
