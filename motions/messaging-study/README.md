# Messaging study intake (Naveen ask, Aug 18 2026)

Goal: absorb what has and hasn't worked in Nate's and Jack's historical outreach (plus Memory Blue: Aidan, Tyler) and abstract the winning patterns into the MessageGen prompts and Lemlist A/B variants BEFORE outreach restarts. Naveen: "the most worthwhile effort we do."

## How to submit (for Nate / Jack)
Drop exports into `inbox/`, any format (.eml, .msg, .csv, screenshots, pasted text files). One file per message or a bulk export, both fine. For each message, whatever you know of:
- channel (email / LinkedIn / phone-followup)
- got a reply? (yes / no / meeting booked)
- who it went to (title + company type is enough; no need to clean it)
- roughly when

Nothing else. Don't curate or pretty it up; the raw material is the value.

## Scoring rubric (applied per message during analysis)
| Dimension | What gets coded |
|---|---|
| Outcome | reply / no reply / meeting / unsubscribe-negative |
| Channel | email / LinkedIn InMail / LinkedIn DM / call follow-up |
| Persona | wfm / cc_ops / bo_claims / bo_shared / finance / cx / exec |
| Opening move | trigger-led / pain-led / company-news-led / generic intro |
| Ask | 15-min CTA / soft question / content offer / no ask |
| Length | short (<75w) / medium / long |
| Proof used | verified metric / customer story / none / [UNVERIFIED claim - flag] |
| Voice markers | phrases that recur in winners, verbatim |

## Analysis output (one pager)
1. What worked: the 3-5 patterns with the strongest reply signal, with verbatim examples.
2. What didn't: patterns overrepresented in silence.
3. Channel truth: where Nate's replies actually came from (his prior: LinkedIn + phone > email).
4. Deltas to apply: exact edits to the Clay MessageGen system prompt and the Lemlist A/B variant set, run through first-draft-engine + copy-sharpener before anything ships.

Caveat kept in every readout: small sample, directional not statistical; verified-claims gate applies to anything lifted into new copy.
