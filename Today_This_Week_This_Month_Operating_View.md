# Today / This Week / This Month Operating View

## Today

### Priority
- Keep the live motion moving with one clear learning loop.
- Review the current target set and choose the strongest next action.

### Must-do
- Check the current outreach list and identify the best next account or wedge.
- Review whether the current message is specific enough to earn a reply.
- Decide whether to continue, tighten, or pause the current wave.

### Reminder
- The goal is signal, not volume.
- One good reply or one clear next step is enough for today.

## This Week

### Focus
- Run one small, instrumented wave.
- Review replies quickly and classify them clearly.
- Tighten the angle based on what the replies show.

### Weekly targets
- One narrow wedge
- One clear message angle
- One small wave
- One review session at the end of the week

### Success bar
- At least one meaningful signal from the week:
  - a reply,
  - a next-step request,
  - or a clear sign that the angle needs adjustment.

## This Month

### Priority
- Turn the current live motion into a repeatable operating rhythm.
- Learn what works from real signal and use that to improve the next wave.
- Keep the motion focused enough to produce useful data.

### Monthly posture
- Optimize what is already live.
- Avoid broad expansion before the current wave proves the angle.
- Use the learnings to decide where to put the next bit of effort.

## Guardrails

- Do not expand the universe just to keep activity up.
- Do not build more infrastructure if the current wave still needs sharpening.
- Do not let the motion drift away from a clear sales purpose.

## Simple decision rule

- If the current angle is producing signal, keep going.
- If it is not, narrow the wedge and tighten the message.
- If it is still unclear, pause and reset before scaling.
