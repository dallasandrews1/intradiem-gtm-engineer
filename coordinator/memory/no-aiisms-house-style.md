Default for every output (notes, copy, docs, website text, chat replies): plain, human, direct. Dallas has asked for this repeatedly across sessions, so treat it as permanent, not per-task.

**Why:** AI-isms and corporate jargon make work read as machine-generated and undercut Dallas's voice with execs like Naveen. Em dashes are his specific tell for "AI wrote this."

**How to apply:**
- Zero em dashes (—). Use periods, commas, colons, or restructure the sentence.
- Cut jargon and filler: leverage, robust, seamless, utilize, delve, landscape, ever-evolving, at scale (as filler), unlock, elevate, streamline, synergy, "the X that Y" padding.
- No throat-clearing or self-reference (don't explain how to read the thing, don't narrate the artifact).
- Short sentences. Plain words. Contractions are fine and good.
- This is in addition to the page-specific rule already verified (deploy page body = 0 em dashes). Re-check every new output before delivering.
