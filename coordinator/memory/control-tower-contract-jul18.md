Jul 18 2026: wrote `Control_Tower_Build_Contract_v1.md` (repo root of `Intradiem GTM Engineer`) so the VS Code agent builds the "control tower" to a defined contract instead of improvising. Trigger: a VS Code session listed 7 high-leverage builds; 6 already exist as coordinator skills (war-room, readout, launch-kit, research stack, objection/reply, motion logic). Only the control tower was a real gap.

**The tower is a read-and-render layer, not greenfield.** The backbone already exists: `gtm-cohesion-layer/engine_state.json` (18 keys, self-described as "one state file every dashboard reads from, fixes dashboard drift"), `impact/impact.json`, `clay_credit_ledger.csv`, `Clay_Build_State_Registry.md`, `tam-outbound-engine/account_plays.json`, `Readout_Log.md`. Two `salesforce-dashboard/*.html` mockups hardcode values and are superseded.

**The one law in the contract:** never render seeded/stale/unverified data as fact. engine_state is currently `_meta.status = "SEEDED — pre-access placeholders"`, funnel all zeros, sends 0 by design. Trust-state (SEEDED/LIVE/STALE/REALIZED) is a first-class badge on every panel; surfaced and realized never share a cell. v1 panels are honest today (build-state, credits, deliverability gate, blockers) and defer the live funnel to v2 once sends exist.

**Brain/hands split (the governing decision):** logic (skills, motion rules, verified-claims, brand) stays in coordinator; the tower only reads and arranges, runs in VS Code (assembler `build_control_tower.py` -> `control_tower_state.json` -> self-contained `Control_Tower.html` -> launchd job). Read-only, never sends/writes/flips a gate. Do NOT let VS Code rebuild any existing skill. See [[surface-split-rule]], [[vscode-gtm-automation-jul17]], [[intradiem-cohesion-layer]], [[three-surface-sync]].

**Reconciliation:** a personal `mission-control.html` already exists (13 panels, relationships/promises/gates) — do not duplicate. Tower owns the live GTM-machine read; mission-control's credit + gate panels should later bind to `control_tower_state.json` so the two don't drift. See [[mission-control-dashboard]].

Recommended refresh model: static snapshot regenerated by launchd (matches existing automation), not a live server. Decision pending Dallas.
