Every time we add something to the Intradiem GTM build, explicitly connect it back to what already exists and is in motion, so neither of us loses the thread as the system grows. Then close each turn with a digestible, simple, plain-language explanation of what changed and how it fits.

**Why:** The portfolio is large (12+ tools, 30+ skills, multiple dashboards, the cohesion layer). Without continuous tie-back it becomes chaos and things silently break or duplicate.

**How to apply:** When building/adding anything, state what it plugs into (which existing engine/dashboard/state file/mandate), update the cohesion-layer README/index so the map stays current, and end with a short "here's how this fits" recap in everyday language — not jargon. See [[intradiem-cohesion-layer]].
