GTM Engineering intro call, Jul 21 2026: Dallas + Naveen + Matt Graves (Director of CSM). Decisions and flags that change how the engine runs:

**STOP / be-aware flags from Matt:**
- **Do not quote Zuar/Greenlight savings or projected-value numbers in prospect copy.** It's an internal averaged model (assumed salary/time, blended across all Stars). Customers "will call us on it." Financial-services buyers reject projected value almost every time. The safe framing is objective activity counts (actions per agent per day, coaching sessions, adherence/handle-time alerts) and let the customer apply their own value.
- **Customer-naming is a contracts/marketing gate, not Dallas's call.** Check Jenna (Contracts — kept a master tracker of quotable vs non-quotable customers) and Cheryl (Marketing — website stories are almost always anonymized). "Spirit vs rule of law": JPMC would have a serious problem being named. Default to category-level ("a top-5 health plan"). Humana is the sole cleared named exception.
- Zuar dashboards can be polluted by miscategorized rules (an admin rule firing 200k times); raw spikes aren't trustworthy without the model.
- Josh's activity-count work exists but denominators were off on a couple metrics; not yet validated.

**Actions taken:** Froze the Intradiem Value Repository as a prospect-facing source (see [[value-repository-frozen-jul21]]). Humana stays as the marquee verified social-proof point.
