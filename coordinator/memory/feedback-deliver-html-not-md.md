Dallas, Sep 2 2026: "I need you to be delivering things to me as htmls as well. I don't like having to find md files."

**Why:** he reads deliverables on the Desktop and in the browser; a markdown file buried in a motion folder is a search, not a handoff.

**How to apply:** anything written for him (sheets, scripts, prep notes, OKR drafts, huddle notes, Q&A) gets a branded HTML page on the Intradiem kit (Roboto, forest/green tokens, inline logo) via `motions/shared/md_to_page.py`, copied to the relevant `~/Desktop/Intradiem Deliverables/<folder>/` and linked by path in the chat. The markdown may stay as source in the repo but is never the thing he is pointed to.
