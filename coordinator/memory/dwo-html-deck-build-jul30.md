**HTML DECKS MUST USE A FIXED SCALED CANVAS (Jul 30, hard lesson):** the deck originally sized slides with `vh`/`vw` + `clamp()`, which rendered perfectly at 1440x810 and **broke at 1000x563** (dense slides 4-5 overflowed into the absolutely-positioned footer logo/page number). Caught only by screenshotting at multiple window sizes. FIX, now the standard for every Intradiem HTML deck: lay slides out on a **fixed 1440x810 canvas** with all interior sizing in px (the values verified at that reference), wrapped in `.stage{position:fixed;inset:0;overflow:hidden}` with `.deck{position:absolute;left:50%;top:50%;width:1440px;height:810px;transform:translate(-50%,-50%) scale(var(--s));transform-origin:center}` and JS `--s = Math.min(innerWidth/1440, innerHeight/810)` on load+resize. Body background follows the slide theme so the letterbox is seamless. Print: `transform:none`, slides 1440x810px, `@page size:15in 8.4375in` (1440x810px = exactly 15x8.4375in at 96dpi). **GOTCHA that cost a debug cycle:** CSS Grid `place-items:center` does NOT center a grid item LARGER than its container (Chrome pins it to start), so the scale pivot was wrong and content clipped right/bottom; absolute + `translate(-50%,-50%)` is deterministic, grid/flex centering is not. Verified identical at 900x600, 1000x563, 1280x720, 1512x850, 1920x1080.

**VISUAL DEFECTS CAUGHT BY SCREENSHOT, NOT BY CODE CHECKS (Jul 30, lesson):** headless Chrome renders (see [[headless-render-workaround]]) exposed two bugs that JS/HTML validation passed clean. (1) **SVG `<use>` shadow-boundary trap:** the logo wordmark was invisible on dark surfaces because outer descendant selectors like `.dark .wm{fill:#fff}` do NOT reliably cross into `<use>` shadow content, so it fell back to forest-on-forest. FIX (now the standard): give the wordmark paths `fill="currentColor"` and set `color` on the logo element, since `color` is inherited and crosses the boundary. This same bug was latent in the US Outbound reference files' `.hero .logo .wm{fill:#FFFFFF}` pattern. (2) The fixed-position HUD hint overlapped the per-slide page number bottom-right; hint moved to bottom-center and now fades 4s after navigation. Also per Dallas: **the logo was too small everywhere** — deck cover 46->76px, per-slide mark 16->28px (hidden on cover slides), doc heroes 44->64/60px, doc footers ->24-26px, 404 ->64px. Always screenshot a deliverable before calling it done.
