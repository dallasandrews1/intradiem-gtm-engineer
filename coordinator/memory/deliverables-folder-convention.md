Finished deliverables always land in `~/Desktop/Intradiem Deliverables/`. Do not create a new staging folder on the Desktop for a batch of work, and do not leave the only copy inside the project repo.

**Why:** Dallas grabs files from that one folder when he shares them in Slack. Anything staged elsewhere is invisible to him and he has to go looking, which he flagged on Aug 6 2026 when a five-file QBR package went to a separate Desktop folder.

**How to apply:** Write working files in the project repo, then copy the shareable versions into `~/Desktop/Intradiem Deliverables/` with clean names (spaces, no underscores between words). Keep the repo copy as the source and re-sync after any edit. See [[naveen-facing-comms-rules]].
