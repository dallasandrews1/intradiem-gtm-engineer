`Clay_Golden_Standard.md` §6 is explicit doctrine: prompt text, persona-lead structures, and number tokens are per-motion by design. A single shared MessageGen Function would freeze one motion's core position across all motions, which is "exactly wrong." So `Clay_MessageGen_SystemPrompt_v2.md` (Stars, now v2.3.0, mirror ahead of live per the known drift in [[clay-golden-standard-and-motion-runbook]]), `Clay_MessageGen_SystemPrompt_BackOffice_v1.md`, and `Clay_MessageGen_SystemPrompt_CostMandate_v1.md` are three genuinely separate, independently-maintained prompts.

Shared across all three: the COPY RULES house style, the SENTENCE FLOW cadence block, the companion critic pattern (figure-integrity + Voice Audit), and the v2.2.3 structural contract (token map, persona routing, core position, number discipline, fallback rules, output format). Core positions differ materially: Stars leads with a verified CMS dollar; Back Office leads with the warm-install-base fact plus a strict no-Intradiem-number law (all public BOO ROI stats are DO-NOT-SEND until cleared by the Value Repository); Cost-Mandate leads with the prospect's own disclosed figure only, gated by the H1 source-verification rule in [[cost-mandate-motion-current-state]].
