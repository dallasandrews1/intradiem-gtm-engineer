2026-08-05: Dallas flagged two things in a drafted Slack message to Naveen: naming the QBR city ("Minneapolis") felt random, and "straw man" isn't how a person talks.

**Why:** context details pulled from memory (locations, calendar specifics) read as showing homework, not as natural speech; the recipient already knows where their own meeting is. Jargon like "straw man" breaks the peer-level human voice ([[naveen-facing-posture]]).

**How to apply:** in short messages, reference shared events the way the participants would ("at the QBR", "this week"), never by details the recipient already knows. Swap consultant terms for plain phrases: "first swing", "nothing's locked", "rough pass", "shape it together".

**Extended 2026-08-05 (same session):** the rule covers presenting DOCUMENTS too. Dallas: external/presenting docs must not carry framework scaffolding that needs explaining, no "KR 1.1 / KR 1.2" numbering, no "O1/O2/O3" codes, no "ratify"/"fait accompli"/"control group"/"artifact"/"telemetry"-style phrasing. Every line should read as something you'd say out loud while presenting. Applied across the channel OKR one-pager: chips became plain labels (Funds the role / Differentiates it / Makes it durable), bullets stand alone as sentences, "ratified" became "set", status became "Draft for discussion".
