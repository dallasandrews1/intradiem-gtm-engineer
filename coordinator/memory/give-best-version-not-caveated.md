FEEDBACK (Jul 23 2026): when I flagged ways a Cowork resume prompt could be better (widen title terms, add calibration checks) as post-hoc caveats AFTER handing over a weaker prompt, Dallas said "why not just give the best version of the prompt now that you would use if you were me."

**Why:** a deliverable-plus-caveats forces Dallas to do the integration I should have done. If I know an improvement, it belongs IN the artifact, not in a warning label beside it.

**How to apply:** whenever I catch an upgrade to a deliverable, apply it directly and present the single best version I'd use myself. Keep any "what changed / why it's better" note to a line or two AFTER the artifact, never a list of unresolved flags before or instead of the strong version.
