Deck: https://allhandsdeckforchrisvegas.netlify.app (Naveen DM'd it Sep 17 2026). Profile from source: one 3.6 MB HTML file, 37 navigable slides, slide-first (arrows, contents button, dots), full-bleed dark forest, animated canvas line field on the title, 514 keyframes, 9 canvases, 3D card entrances, embedded interactive product mockups ("Tap each one"). Tokens: forest #014637, orange #F58220, lime #A5CE38 as the main accent, cream paper #F7F5EF, Open Sans throughout. Same logo and forest and orange as the Jul 30 kit, but NOT Roboto and NOT green #2DB56E. Unresolved which is current for leadership decks; check with whoever owns brand before switching anything. See [[intradiem-brandkit-current-jul30]].

Recommendation given to Dallas (his decision pending): do not restyle the working pages (dashboard, manager cards, assessment, contracts). They are tools people operate, and motion next to numbers costs trust. Raise ONLY the exec presentation (the briefing's present mode) to that bar, with motion that carries meaning: an animated loop diagram as the signature visual, live slides that embed the real working pages so the presenter operates the actual tool inside the deck, numbers that count up from the engine state. The contrast to keep: theirs is a vision deck where motion stands in for product; ours is a working system, so the flex is leaving the slides and driving the real thing.
