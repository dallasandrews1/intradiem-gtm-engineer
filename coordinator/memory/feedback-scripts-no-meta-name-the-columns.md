Sep 4 2026, on the all-hands demo script v3: Dallas cut the "what changed from v2" and "what to ask Naveen for" sections as unnecessary fluff, and asked for the enrichment step to name the exact columns being run.

**Why:** a script is read while doing the thing; anything that is not the next line to say or click slows him down. Rationale and asks belong in chat.

**How to apply:** for any page Dallas follows live (recording scripts, runbooks, UI sheets), start at the content; put version rationale and asks in the chat reply only. At each execution step name the workbook, table, view, the column to run, what it fills, and what the viewer sees, as a small table.
