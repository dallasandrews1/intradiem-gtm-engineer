Refactor (Aug 31 2026, worktree vs-code-agents-window-usage): `bo_set.py` loads `sets/<name>.json` (rep, files, built list, drop / priority / manual_under / title_override / dual / verify / phrases / collision, topics_extra, func_extra, select mode). `bo_titles.py` holds the shared vocabulary (band, func, lanes, is_root, TOPICS, topics) so the sweep filter and the build sheets never drift. Scripts: `build_map_build_sheets.py`, `build_bo_map_artifact.py`, `check_all.py`, `diff_built_maps.py`, `audit_maps.py` all take `--set` (default inger, or env BO_SET). Inger regen proven byte-identical (CSV, MD, bench, HTML) after the refactor; pre-refactor copies kept as `_build_*_v2_prerefactor.py.bak`.

Net-new (no AM map) path, first used for Nate's six: raw Clay query-mode sweeps land in `sweeps/<set>/<account>.csv` (0 credits; run queries serially, the workspace rate-limits concurrent searches; `run --limit 500` is a forward-only iterator, loop on hasMore) -> `filter_sweep.py --set` (dedupe by name, Director+ level gate, front-line / sales / legal / IT / HR / field-ops / clinical / IC / CEO gates, credential checks MD/RN/FSA, topic gate, per-account `require_specific_topic` for utilities) -> `build_map_build_sheets.py` with `"select":"balanced"` (executives tiered ops > finance > other and shorter corporate titles first, VP layer spread across functions, directors only under a manager on the map, lanes 3 and 4 held to three, `require_url` benches anyone not yet bridged) -> `nate_bridge_input.csv` (map + top 12 bench per account) -> Clay MCP find-and-enrich-list-of-contacts in subagents (0 credits) -> `apply_bridge.py --set` (URL, fresh title, leavers excluded, not-found benched, dual recorded) -> `sf_check.py --set --only-map` (Audiences people by LinkedIn slug then exact name; field ids in the script) -> `verify_live.py --set --go` (Enrich Person routine, batched 30 per run per account, `current_experience` empty = left/retired, company must match `accounts[].aliases`) -> rebuild -> `check_all.py --set` -> page -> stage to deploy-backoffice-maps/<set>/.

Lessons: bank "Vice President" titles include ICs (analyst, team lead, specialist) and "Manager" titles carry SVP band; Regions/Truist directors sit in the Manager seniority bucket in Clay, so director-depth needs seniority ("Director","Manager") with a title-band gate; Paychex is sales-heavy and thin at Director+ ops (11 on the map is what the index holds); National Grid bare "Operations" titles are field ops, hence the specific-topic rule.

**How to apply:** any new rep request = copy sets/nate.json, set accounts/domains/SF ids/aliases, run the chain above; never edit Inger's files by hand. Related: [[nate-six-accounts-bo-maps-aug31]], [[inger-account-maps-build-aug25]], [[clay-free-sourcing-path]].

**Routine batch results arrive in completion order (Aug 31 lesson, cost ~87 credits):** `clay routines runs get` returns `data` items out of input order; matching by position shifted titles between people across a whole map set. `verify_live.py` now matches each result by the profile `url` slug the routine returns (fallback: unique name match within the run), saves raw JSON per run in `_live_raw/`, and the routine's canonical URL can differ from the bridge URL. Any future batched routine parse must key on a field inside the result, never on order.
