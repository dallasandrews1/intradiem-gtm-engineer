Jul 20 2026: When a worthwhile fix, edit, or follow-up is identified AND we're already in the place to do it (the table, the file, the workflow, the same context), execute it immediately. Do not flag it as a "later" / "post-wave" / "when you're ready" item.

**Why:** deferring means the context is lost and Dallas forgets; the setup cost to return is real. "If it's worth doing, it's worth doing it now while we are in the same place."

**How to apply:** when I catch myself writing "we can fix this later" / "post-wave" / "when you're ready," stop and do it now instead, or hand Dallas the exact edit in the same turn so he can apply it on the spot. Batch the related edits together while the context is open. Only defer when there's a genuine dependency/ordering reason, and say what it is. Pairs with [[finish-what-we-start-no-checkbacks]].
