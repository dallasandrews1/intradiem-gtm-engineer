**Tokens (verbatim):** --green:#2DB56E · --green-600:#228752 · --green-300:#7BD3A0 · --green-100:#C4ECD4 · --forest:#014637 · --orange:#F58220 · --orange-600:#D96D12 · --blue:#0F4C99 · --ink:#202020 · --ink-2:#5A5A5A · --ink-3:#9A9A9A · --bg:#FFFFFF · --sidebar:#F5F4F2 · --zebra:#FAFAFA · --tint:rgba(45,181,110,.12) · --tint-soft:rgba(45,181,110,.08) · --line:#E0E0E0 · radius 8px.

**Type:** Roboto (400/500/700/900) body+display, headlines weight 900 with letter-spacing -.02em; Roboto Mono (500/600) for eyebrows/labels/tables, uppercase, .16em eyebrows. NOT Playfair/DM Sans/JetBrains.

**Signature moves:** forest #014637 hero/dark surfaces with a radial green glow (radial-gradient rgba(45,181,110,.3)); eyebrows are GREEN (green-600 on light, green-300 on dark), orange #F58220 is the action/priority accent (now-stage borders, ask highlights, spark words); callouts on tint-soft bg with tint border; statbands on forest with green-300 accent numbers and mono labels in #9DBBAE; tables with mono green-600 headers and zebra rows; gates/badges pattern (tint bg green-600 text, orange variant for open/caught).

**Logo:** the official Intradiem mark as an inline SVG `<symbol id="ilogo" viewBox="0 0 187 46">` (icon paths #FDBF40/#F58220/#A5CE3A/#2CB56E + wordmark paths class="wm"). `.wm` fill = #014637 on light, #FFFFFF on dark heroes. Decks: logo-hero ~46px on the title slide, 16px .slidelogo bottom-left + mono page number bottom-right on every slide. Docs: 40-44px in hero, 14-15px centered in footer. Copy the symbol verbatim from any of the standard files (DWO_Story_Deck.html, US_Outbound_Strategy_Deck.html).

**Deck print standard:** @page size 13.333in 7.5in margin 0; slides relative, one per page, print-color-adjust exact.

**How to apply:** every new Intradiem deliverable (docs, decks, dashboards) uses these tokens, this type system, and the inline logo.
