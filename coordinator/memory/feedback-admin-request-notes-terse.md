Sep 11 2026, drafting the reason note for the Intradiem GTM Brain Slack app install request, Dallas asked to strip all fluff and unnecessary phrases so it sounds like him, not AI.

**Why:** admin-facing notes are scanned for risk facts (scope, data access, where it connects); pleasantries read as AI and slow the read.
**How to apply:** what it is and does in one or two sentences, then the security facts (read-only, scopes, what it does not read, where it connects, how it authenticates). No closing offer, no "internal", no hedges. Same rule as [[feedback-slack-voice-short-casual]] applied to admin asks. See [[slack-gtm-brain-app-created-sep11]].
