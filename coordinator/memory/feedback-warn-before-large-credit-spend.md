On 2026-08-21, mid-build of the Sep 2 webinar net-new list, Dallas wrote: "If you need to spend a large amount of credits you need to be warning me before you do it." This came after "spend credits where needed" the day before; the blanket permission does not cover large runs.

**Why:** the ~72K credits are a one-time proof budget and the renewal story depends on every burn being attributable. A surprise four-figure drop, even if useful, reads as loss of control.

**How to apply:** for any enrichment or waterfall over roughly 100 credits, (1) run a 10-20 row test and measure the actual per-row cost and hit rate, (2) state rows x cost = estimate and the ceiling, (3) stop and wait for his explicit go, (4) append the ledger est row before starting and the actual after. Reads, searches, segments, workflow builds, and Audiences writes are free and need no warning. Related: [[carter-webinar-lead-engine-aug20]], [[clay-free-sourcing-path]].


**Revised Sep 3 2026:** while the Quality fresh pull was running, Dallas wrote: "I think we need to revise this 100 credit line and double it or something we need to be able to run actual campaigns and find all the people that are relevant and credible for these things." New line: spend up to 200 credits on a sourcing or enrichment run without stopping, as long as the estimate is stated up front and the actual is logged after. Above 200, the Aug 21 sequence still applies (small test, estimate, explicit go). Same-day calibration: the Clay-managed work-email workflow measured ~1.6 credits per row all-in on 41 rows (67 credits), not the ~0.7 the node description implied; use 1.6 for future estimates.
