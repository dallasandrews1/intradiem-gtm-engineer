# League Program Catalog — Quality Measure Mappings

This reference file contains the 128 League health programs that have confirmed quality measure
mappings. Use this when someone asks about specific League programs, which programs exist for
a given condition, or what measures a specific program connects to.

**Source**: All_Content League CSV — Quality Measures Mapping field, April 2026
**Coverage**: 128 of 536 total programs have confirmed measure mappings
**Not included**: 408 programs without measure mappings (Challenges, Benefits, many Fitness,
Mental Health, and some Chronic Condition programs) — see Stage 2 roadmap in skill notes

---

## How to Use This Reference

When someone asks what programs League has for a condition:
1. Find the relevant section below
2. List programs by name with their quality measure connections
3. Note content type (Opt-In = member-initiated; Suggested = platform-surfaced; Journey Goals = structured goals)
4. Flag geographic availability if relevant (US Only / CAN Only / US & CAN)

When someone asks what measures a specific program connects to:
1. Find the program by name
2. List all HEDIS, Stars, and Medicaid measures exactly as shown
3. Connect to relevant condition playbook for full outcomes context
