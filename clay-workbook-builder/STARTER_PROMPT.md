# Clay workbook build starter

Use this when you are moving from a build pack into live Clay work.

## Prompt

I need help moving this Clay workbook build from docs into the live Clay workflow lane.

Please:
1. Read the current build state in Clay_Build_State_Registry.md.
2. Read the house rules in Clay_Golden_Standard.md and New_Motion_Build_Runbook.md.
3. Identify what is already built, what is still missing, and whether this should be handled in the live Clay UI, in local Claude Code CLI, or in Cowork MCP.
4. Be explicit about current environment limits. Do not overclaim Clay capabilities. If the task needs enterprise-only Clay access, say so clearly and mark it as a manual or blocked step.
5. Give me a concise handoff plan for the next step.
6. Call out any risk or blocker before I start the build.
