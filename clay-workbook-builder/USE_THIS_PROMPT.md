# Use this prompt for the next Clay handoff

Use this when you are moving from planning into a Clay workbook build.

## Prompt

I need a precise handoff for this Clay workbook build.

Please:
1. Read the repo build state and runbook first.
2. Separate the work into four lanes:
   - Claude Code CLI
   - Cowork MCP
   - manual Clay UI
   - blocked by current access limits
3. Be explicit about what is possible in this environment and what is not.
4. Do not overclaim Clay execution capability.
5. Give me the single next action only.
6. If anything requires enterprise Clay access, label it clearly as blocked or manual.
