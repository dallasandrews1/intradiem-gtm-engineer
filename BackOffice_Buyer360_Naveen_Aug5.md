# The Back-Office Buyer, 360 View
**Source: Mary Ann persona rebuild (Jul 26), 285 contacts across 15 companies, director level and up. Full lists live in the four Jul26 CSVs; everything below is a curated slice with LinkedIn URLs.**

The same four seats show up in every sector. That's the 360:

1. **COO / SVP Operations**: the executive entry point; owns the cost line the tool moves.
2. **Operations leaders**: run the queues day to day (claims, appeals, disputes, payments, shared services); feel the pain first.
3. **Product owners / WFM**: the internal seat the tool would actually sit under, separate from the ops line.
4. **Claims IT / operations technology**: the tech decision makers who approve and integrate. This is the seat Mary Ann flagged as missing from the first pull.
